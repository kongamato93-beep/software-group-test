# 接口测试用例表

> 被测系统：狂神の小社区（kuang_simple_bbs），`http://localhost:8080`
> 测试工具：Apifox CLI 2.2.12
> 用例总数：45 条（全部已执行），全部纳入 Apifox 自动化测试场景
> 测试账号：`root` / `123456`
> 用例设计方法：等价类划分法、边界值分析法、场景法、错误推测法

## 一、用例设计思路

| 方法 | 应用点 |
|---|---|
| 场景法 | 场景一按「登录 → 浏览列表 → 发帖 → 查看详情 → 删除」串成一条完整业务链 |
| 等价类划分法 | 路径参数 `page`/`limit`/`bid` 划分为有效等价类（正常值）与无效等价类 |
| 边界值分析法 | page=0、limit=999999 等边界值 |
| 错误推测法 | 未登录直接访问受限接口、访问不存在的资源 |
| 接口文档覆盖 | 场景三覆盖 OpenAPI 文档中 39/40 个操作，覆盖率 97.5% |
